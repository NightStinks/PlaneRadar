PlaneRadar

Flash firmware directly to your ESP32-C3 from Chrome or Edge — no drivers needed.

  1. Connect the ESP32-C3 via USB
  2. Click Install and select the serial port
  3. Wait ~60 s for flash + reboot
  4. Connect to PlaneRadar-Setup Wi-Fi to configure

Requires Chrome or Edge on desktop. iOS/Firefox not supported (no WebSerial).
